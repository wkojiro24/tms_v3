# 運行管理 要件定義書

## 概要

### 目的
- デジタコデータに基づく日報管理
- 運行実績の記録・分析
- ロジユソーからの移行

### 現状（AS-IS）
- デジタコ（矢崎エストラウェブ）から運行データが自動収集される
- 各営業所の事務担当者がロジユソーに手入力している
- 日報の作成・確認・承認をロジユソー上で実施

### 目標（TO-BE）
- 本システムで日報管理を完結
- デジタコデータからの自動入力で入力作業を効率化
- 他機能（配車、車両、給与）との連携

### 使用機器
- **デジタコ**: 矢崎エストラウェブ（YAZAKI Estra Web）
- **出力形式**: PDF/CSV（日報形式）

### 移行元システム
- **ロジユソー21** Ver 3.1.x
- 主要機能：日次処理、売上管理、車両管理、請求管理、デジタコ処理

### 新システムの目標
1. **日報入力の自動化**: デジタコ→日報を自動生成（手入力を最小化）
2. **請求書発行**: 運送明細から請求書を自動生成
3. **車両別経費管理**: 燃料費、ETC、修理費等を車両に紐付け
4. **車両別収支**: 売上 - 経費 = 車両別利益を算出

### メニュー構成

```
運行管理
├─ 日報管理
│   ├─ 日報一覧
│   ├─ 日報入力（デジタコから自動生成）
│   └─ 日報承認
├─ 運送明細（売上）
│   ├─ 運送明細一覧
│   ├─ 運送明細入力
│   └─ 請求書発行
├─ 車両経費
│   ├─ 経費一覧
│   ├─ 経費入力（燃料/ETC/修理等）
│   └─ 経費取込（CSV/ETC明細）
├─ 車両別収支
│   ├─ 車両別原価計算書
│   ├─ 車両別経費管理表
│   └─ 車両別輸送実績表
├─ 運行実績
│   ├─ 車両別実績
│   └─ ドライバー別実績
└─ デジタコ連携
    ├─ データ取込
    └─ 取込履歴
```

### 8-6. ETC取込処理フロー

```
1. 関運協ポータルから走行明細CSV・総括表CSVをダウンロード
2. システムにCSVをアップロード（Shift-JIS→UTF-8変換）
3. ETCカード番号から車両を自動マッチング（ETCカードマスタ参照）
4. VehicleExpense（車両経費）に自動登録
   - expense_type_id: 00604（プレート代/ETC）
   - etc_card_no: カード番号
   - entry_ic / exit_ic: IC名称
   - amount: 通行料金
5. 重複チェック（利用日+シーケンスで判定）
6. 未登録カード番号があればアラート表示
7. 経費一覧で確認・車両紐付け修正
```

3. **適用日管理**: FROM/TOで履歴管理されているため、移行時は最新レコードを選択
4. **使用停止フラグ**: 0=使用中のレコードのみ移行
5. **エンコーディング**: Shift-JIS → UTF-8への変換が必要
6. **改行コード**: CR+LF → LFへの変換推奨
