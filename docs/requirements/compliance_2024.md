# 2024年問題対応 要件定義書

## 概要

### 目的
- 改善基準告示（2024年4月施行）への準拠状況をリアルタイムで監視
- 配車担当者が迷わず判断できるよう、システムで自動判定
- 違反リスクの事前検知・アラート

### 関連機能
- 人事機能（勤怠管理、KING OF TIME連携）
- 配車機能（配車時の稼働可能時間表示）

---

## 1. 改善基準告示ルール体系

### 1-1. 拘束時間

#### 基本ルール
| 項目 | 基準値 | 備考 |
|------|--------|------|
| 年間拘束時間 | 3,300時間以内 | 原則 |
| 月間拘束時間 | 284時間以内 | 原則 |
| 1日拘束時間 | 13時間以内 | 始業から24時間で計算 |

#### 例外条件

**例外1: 労使協定による延長**
```
条件: 労使協定を締結している場合
  → 年間: 3,400時間まで
  → 月間: 310時間まで（年6ヶ月まで）

追加条件:
  - 284時間超の月が連続3ヶ月を超えない
  - 月の時間外+休日労働が100時間未満となるよう努める
```

**例外2: 1日の最大拘束時間15時間**
```
条件: 労使協定がある場合
  → 1日最大15時間まで延長可

注意: 15時間超は原則不可
```

**例外3: 長距離貨物運送の特例（16時間）**
```
条件:
  - 1運行が450km以上の長距離貨物運送
  - かつ、運行中の休息が住所地以外

  → 1週につき2回まで、1日最大16時間まで延長可
```

**例外4: 隔日勤務**
```
条件: 隔日勤務の場合
  → 2暦日で21時間以内

追加条件: 夜間4時間以上の仮眠がある場合
  → 2暦日で24時間まで延長可（週3回まで）
```

**例外5: 2人乗務**
```
条件: 2人乗務の場合
  → 最大20時間まで延長可

追加条件A: 車両に規定サイズ（長198cm×幅80cm以上）のベッドがあり、
           かつ継続11時間以上の休息後
  → 最大24時間まで延長可

追加条件B: 同ベッドで8時間以上の仮眠がある場合
  → 最大28時間まで延長可
```

### 1-2. 休息期間

#### 基本ルール
| 項目 | 基準値 | 備考 |
|------|--------|------|
| 休息期間 | 継続11時間以上 | 努力義務 |
| 休息期間（下限） | 継続9時間以上 | 絶対下限 |

#### 例外条件

**例外1: 長距離貨物運送の特例**
```
条件:
  - 1運行が450km以上の長距離貨物運送
  - かつ、運行中の休息が住所地以外

  → 週2回まで、継続8時間以上でも可

追加条件: 8時間以上9時間未満の休息を取った場合
  → 運行終了後に継続12時間以上の休息を付与すること
```

**例外2: 分割休息の特例**
```
条件: 継続9時間の休息確保が困難な業務の場合
  → 月の全勤務回数の50%まで分割可

分割パターンA（2分割）:
  - 1回あたり3時間以上
  - 合計10時間以上

分割パターンB（3分割）:
  - 合計12時間以上
  - 3分割の日が連続しないよう努める
```

**例外3: 隔日勤務**
```
条件: 隔日勤務の場合
  → 勤務終了後、継続20時間以上の休息が必須
```

**例外4: フェリー乗船**
```
原則: フェリー乗船時間は休息期間として計上可

条件: 乗船時間が8時間超（2人乗務は4時間超）の場合
  → フェリー下船時刻が勤務開始時刻となる
```

#### 基本ルール
| 項目 | 基準値 | 備考 |
|------|--------|------|
| 連続運転時間 | 4時間以内 | |
| 運転中断 | 10分以上の休憩 | 原則 |

**例外1: 駐停車不可の場合**
```
条件: サービスエリア等に駐停車できない事情がある場合
  → 連続運転4時間30分まで延長可
```

|------|--------|------|

### 1-6. 予期しない事象への対応

```
対象事象:
  - 交通事故
  - 車両故障
  - 天災
  - 道路封鎖
  - フェリー欠航
  等

条件: タコグラフ等の客観的記録で確認できる場合
  → 対応時間を以下から除外可能:
     - 1日拘束時間
     - 2日平均運転時間
     - 連続運転時間

注意: 月間拘束時間等からは除外不可

事後対応: 予期しない事象への対応後は、
  → 継続9時間以上の休息を付与すること
```

## 2. パートタイム労働者の時間規制

### 2-1. 基本ルール

| 項目 | 基準値 | 備考 |
|------|--------|------|
| 週所定労働時間 | 契約による | 通常40時間未満 |
| 1日所定労働時間 | 契約による | 通常8時間未満 |
| 時間外労働 | 所定時間を超えた分 | 割増賃金対象 |

### 2-2. 管理項目

| 項目 | 説明 |
|------|------|
| 契約時間 | 週・月の所定労働時間 |
| 実労働時間 | 実際の労働時間 |
| 超過時間 | 契約時間を超えた分 |
| 社会保険加入判定 | 週20時間以上で加入対象 |

### 2-3. アラート条件

```
警告1: 週20時間超過
  → 社会保険加入義務の可能性

警告2: 週30時間接近
  → フルタイム労働者との均衡待遇確認

警告3: 契約時間超過
  → 時間外労働として割増賃金対象
```

## 3. システム実装

### 3-1. データモデル

**DriverComplianceStatus（コンプライアンス状況）**

| 項目 | 説明 |
|------|------|
| employee_id | 対象従業員 |
| target_date | 対象日 |
| monthly_restraint_hours | 月間拘束時間 |
| yearly_restraint_hours | 年間拘束時間 |
| monthly_overtime_hours | 月間時間外労働 |
| yearly_overtime_hours | 年間時間外労働 |
| daily_driving_hours | 1日運転時間 |
| weekly_driving_hours | 週運転時間 |
| rest_period_hours | 休息時間 |
| continuous_driving_hours | 連続運転時間 |
| status | ステータス（ok/warning/violation） |
| alerts | アラート内容（JSON） |

**EmployeeWorkContract（雇用契約）**

| 項目 | 説明 |
|------|------|
| employee_id | 対象従業員 |
| employment_type | 雇用形態（full_time/part_time/contract） |
| weekly_hours | 週所定労働時間 |
| daily_hours | 1日所定労働時間 |
| has_labor_agreement | 労使協定有無 |
| long_distance_enabled | 長距離特例適用可 |
| two_driver_enabled | 2人乗務可 |
| effective_from | 契約開始日 |
| effective_to | 契約終了日 |

### 3-2. 判定ロジック

```ruby
class ComplianceChecker
  def check_daily_restraint(employee, date)
    hours = calculate_daily_restraint(employee, date)
    contract = employee.work_contract

    # 基本ルール: 13時間
    limit = 13

    # 例外1: 労使協定あり → 15時間
    if contract.has_labor_agreement?
      limit = 15
    end

    # 例外2: 長距離貨物運送（週2回まで） → 16時間
    if long_distance_delivery?(employee, date) &&
       住所地外宿泊?(employee, date) &&
       週の16時間回数(employee, date) < 2
      limit = 16
    end

    # 例外3: 2人乗務
    if two_driver_operation?(employee, date)
      limit = 20

      # ベッド付き車両で11時間休息後
      if vehicle_has_bed?(employee, date) &&
         previous_rest >= 11
        limit = 24
      end

      # 8時間仮眠あり
      if nap_during_operation?(employee, date) >= 8
        limit = 28
      end
    end

    # 判定
    if hours > limit
      { status: :violation, message: "拘束時間超過（#{hours}h/#{limit}h）" }
    elsif hours > limit * 0.9
      { status: :warning, message: "拘束時間注意（#{hours}h/#{limit}h）" }
    else
      { status: :ok }
    end
  end

  # 他の判定メソッド...
end
```

## 備考

- 改善基準告示は複雑な条件分岐があるため、システムで自動判定することで配車担当者の負担を軽減
- 例外条件を適用する場合は、その根拠（労使協定、長距離運行記録等）を記録として残す
- タコグラフ等の客観的記録との突合も将来的に検討
