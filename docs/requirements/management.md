# 経営機能 要件定義書

## 概要

### 目的
- 財務諸表の作成・可視化
- 資金・資産の管理
- 保険・事故案件の管理
- 法務（契約書）管理
- 業界関連情報の収集

### メニュー構成

```
経営
├─ 財務諸表
│   ├─ PL（損益計算書）
│   ├─ BS（貸借対照表）
│   └─ キャッシュフロー計算書
├─ 資金管理
│   ├─ 銀行借入
│   └─ 仕訳明細
├─ 資産管理
│   ├─ 固定資産
│   ├─ 備品管理
│   └─ リース管理
├─ 保険・事故
│   ├─ 保険管理
│   └─ 事故案件管理
├─ 法務
│   └─ 契約書管理
└─ リンク集
    └─ 運輸支局、トラック協会、助成金等
```

## 1. 財務諸表

### 1-1. PL（損益計算書）

| 機能 | 説明 | 実装状況 |
|------|------|----------|
| 月次PL | 月別の収益・費用・利益 | 実装済み |
| 年次PL | 年度累計の損益計算書 | 実装済み |
| 前年比較 | 前年同月・前年度との比較 | 実装済み |
| 部門別PL | 部門ごとの損益 | 実装済み |
| 勘定科目ドリルダウン | 勘定科目クリックで仕訳明細をモーダル表示 | 実装済み |

#### 勘定科目ドリルダウン機能

P/L画面で勘定科目名の横にある↗アイコンをクリックすると、該当勘定科目の仕訳明細をモーダルで表示する。

**表示項目**
| 項目 | 説明 |
|------|------|
| 日付 | 仕訳の日付（MM/DD形式） |
| 補助科目 | 補助科目名。ない場合は相手勘定（買掛金等）の補助科目から取引先名を取得 |
| 相手科目 | 同一伝票の相手勘定科目名 |
| 借方 | 借方金額 |
| 貸方 | 貸方金額 |

**集計**
- 借方計・貸方計をバッジで表示
- 最大100件まで表示

## 6. リンク集

### 6-1. 機能概要

管理者が業界関連リンクを登録・管理し、全社員が参照できる。

### 6-2. Phase 1（基本機能）

| 機能 | 説明 |
|------|------|
| リンク登録 | URL、タイトル、説明、カテゴリ |
| カテゴリ管理 | 運輸支局/トラック協会/助成金/法令等 |
| 表示順管理 | ドラッグ&ドロップで並び替え |
| 一覧表示 | カテゴリ別にリンク一覧表示 |

#### 想定データモデル

**LinkCategory（リンクカテゴリ）**

| 項目 | 説明 |
|------|------|
| name | カテゴリ名 |
| position | 表示順 |

**ExternalLink（外部リンク）**

| 項目 | 説明 |
|------|------|
| link_category_id | カテゴリ |
| title | リンクタイトル |
| url | URL |
| description | 説明 |
| position | 表示順 |
| crawl_enabled | クロール対象 |
| last_crawled_at | 最終クロール日時 |
| last_content_hash | コンテンツハッシュ（変更検知用） |

### 6-3. Phase 2（自動クロール・通知）

| 機能 | 説明 |
|------|------|
| 定期クロール | 登録URLを定期的にクロール |
| 更新検知 | ページ内容の変更を検知 |
| 自動投稿 | 更新があれば「お知らせ」に自動投稿 |
| 助成金抽出 | 新着助成金情報の抽出（将来的にAI活用も） |

#### 想定カテゴリ例

- 運輸支局（関東運輸局、各地方運輸局等）
- トラック協会（全日本トラック協会、都道府県別）
- 助成金・補助金（国交省、環境省、経産省等）
- 法令関連（貨物自動車運送事業法、道路運送車両法等）
- 業界団体（日本物流団体連合会等）
- その他
