- システム全体の設定・マスタ管理
- ユーザー・権限管理

### 1-4. 権限体系

現在のシンプルな2段階権限:

| 権限 | 説明 | アクセス範囲 |
|------|------|-------------|
| staff | 一般ユーザー | 自分の情報、許可された機能 |
| admin | 管理者 | 全機能アクセス可能 |

#### KING OF TIME連携詳細

| 取得データ | 用途 |
|------------|------|
| 日別勤怠データ | 出勤・退勤時刻、休憩時間 |
| 月次集計データ | 総労働時間、残業時間、深夜時間 |
| 休暇データ | 有給取得、代休、特別休暇 |
| スケジュールデータ | シフト情報 |

**API仕様**: https://developer.kingtime.jp/

```
同期フロー:
1. 日次バッチ（毎日AM3:00）
   ↓
2. 前日の勤怠データを取得
   ↓
3. AttendanceRecord に保存
   ↓
4. 2024年問題チェッカーが自動計算
   ↓
5. 警告があればアラート生成
```

#### マネーフォワード連携詳細

| 取得データ | 用途 |
|------------|------|
| 仕訳データ | 仕訳明細の自動取込 |
| 勘定科目マスタ | 科目コードの同期 |
| 部門マスタ | 部門コードの同期 |
| 取引先マスタ | 荷主情報との紐付け |

**API仕様**: https://corp.moneyforward.com/service/api/

```
同期フロー（仕訳）:
1. 日次バッチ（毎日AM4:00）
   ↓
2. 前日の仕訳データを取得
   ↓
3. 分類ルールに基づき自動マッピング
   ↓
4. JournalEntry / JournalLine に保存
   ↓
5. 車両別P/L に自動反映
```

**OAuth認証フロー**:
```
1. 管理者が「OAuth認証開始」クリック
   ↓
2. マネーフォワードのログイン画面にリダイレクト
   ↓
3. ユーザーが認可
   ↓
4. コールバックでアクセストークン取得
   ↓
5. リフレッシュトークンを暗号化して保存
   ↓
6. 定期的にトークンを自動更新
```
