# ダッシュボード 要件定義書

## 概要

### 目的
- ログイン後の最初の画面として、業務に必要な情報を一覧表示
- 各機能のサマリー・アラートを集約し、すぐにアクションできるようにする
- 役職・職種に応じた情報の出し分け
- 業界情報・安全情報の共有

### メニュー構成

```
ホーム（ダッシュボード）
├─ 要対応アラート
├─ 今日の配車状況（配車担当向け）
├─ 収支サマリー（経営層向け）
├─ KPIウィジェット
├─ お知らせ
├─ 業界ニュース
├─ 安全情報・スローガン
└─ 天気予報
```

## 1. 役職別ダッシュボード

### 1-1. 表示の出し分け

| 役職/職種 | 表示内容 |
|----------|---------|
| 経営者/役員 | 全体KPI、収支サマリー、全アラート、業界ニュース |
| 管理職 | 担当部門のKPI、アラート、配車状況、業界ニュース |
| 配車担当 | 今日の配車状況、車両稼働、ドライバー状況、天気 |
| 人事担当 | 勤怠状況、2024年問題、契約更新、採用状況 |
| 経理担当 | 収支サマリー、承認待ちワークフロー |
| ドライバー | 自分の予定、研修、お知らせ、安全情報、天気 |
| 一般社員 | お知らせ、自分の申請状況、研修 |

### 1-2. ウィジェットの表示/非表示設定

- 管理者がデフォルト設定を定義
- ユーザー個人でウィジェットの表示/非表示をカスタマイズ可能（将来）

## 5. KPIウィジェット

### 5-1. 運送会社KPI

```
KPI（2024年12月）
┌─────────────────┬─────────────────┬─────────────────┐
│ 車両稼働率      │ 実車率          │ ドライバー生産性│
│ 86.5%          │ 72.3%          │ ¥1,245,000     │
│ 前月比 +2.1%    │ 前月比 -1.2%    │ 前月比 +3.5%   │
│ [████████░░]    │ [███████░░░]    │ 目標比 +5.2%   │
└─────────────────┴─────────────────┴─────────────────┘
┌─────────────────┬─────────────────┬─────────────────┐
│ 燃費            │ 事故件数        │ 2024年問題準拠率│
│ 4.2 km/L       │ 0件            │ 95.2%          │
│ 前月比 +0.1     │ 無事故 128日    │ 警告 3名       │
└─────────────────┴─────────────────┴─────────────────┘
```

### 5-2. KPI一覧

| カテゴリ | KPI | 説明 | 計算方法 |
|---------|-----|------|----------|
| **稼働** | 車両稼働率 | 車両の稼働状況 | 稼働台数 / 保有台数 × 100 |
| | 実車率 | 積載走行の効率 | 実車距離 / 総走行距離 × 100 |
| | 積載率 | 積載効率 | 平均積載量 / 最大積載量 × 100 |
| **効率** | ドライバー生産性 | 1人あたり売上 | 売上 / ドライバー数 |
| | 燃費 | 燃料効率 | 走行距離 / 燃料使用量 |
| | 1kmあたりコスト | コスト効率 | 総コスト / 総走行距離 |
| **収益** | 売上高 | 月次売上 | 合計売上 |
| | 営業利益率 | 収益性 | 営業利益 / 売上 × 100 |
| | 車両別利益 | 車両ごとの収益 | 車両P/Lより |
| **安全** | 事故件数 | 月間事故数 | 報告された事故数 |
| | 無事故日数 | 連続無事故日数 | 最後の事故からの経過日数 |
| **人事** | 離職率 | 年間離職率 | 退職者数 / 平均従業員数 × 100 |
| | 有給取得率 | 有給消化状況 | 取得日数 / 付与日数 × 100 |
| | 2024年問題準拠率 | コンプライアンス | 基準クリア人数 / 対象人数 × 100 |

### 5-3. KPI目標設定

管理者が月次・年次の目標値を設定可能。

```ruby
# データモデル: KpiTarget（KPI目標）
| 項目 | 説明 |
|------|------|
| kpi_type | KPI種別 |
| target_year | 対象年 |
| target_month | 対象月（null=年次） |
| target_value | 目標値 |
| unit | 単位（%、円、件等） |
```

## 備考

- マルチテナント対応（TenantScoped）
- 権限に応じた情報の出し分け
- パフォーマンス: 各ウィジェットは非同期読み込み
- キャッシュ: 天気・ニュースは適切にキャッシュ
- スローガンはドライバー画面で最も目立つ位置に配置
