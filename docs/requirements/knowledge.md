# ナレッジ・FAQ機能 要件定義書

## 概要

### 目的
- 社内ノウハウ・マニュアルの一元管理と共有
- よくある質問（FAQ）の整備による問い合わせ削減
- 新人教育・研修資料の効率的な配信
- 業務知識の属人化防止

### 関連機能
- 人事機能（教育・研修管理）
- お知らせ機能

### メニュー構成

```
ナレッジ
├─ ドキュメント
│   ├─ ドキュメント一覧
│   ├─ 新規作成/編集
│   ├─ カテゴリ管理
│   └─ タグ管理
├─ FAQ
│   ├─ FAQ一覧
│   ├─ FAQ作成/編集
│   └─ カテゴリ管理
├─ マニュアル
│   ├─ 操作マニュアル
│   ├─ 業務マニュアル
│   └─ 緊急対応マニュアル
└─ 検索
```

## 1. ドキュメント管理

### 1-1. 概要

社内のノウハウ、手順書、規程などを登録・共有する機能。

| 機能 | 説明 |
|------|------|
| ドキュメント登録 | テキスト記事、ファイル添付 |
| カテゴリ・タグ管理 | 分類と検索性向上 |
| バージョン管理 | 更新履歴の保持 |
| 権限設定 | 閲覧・編集権限の制御 |
| アクセス分析 | 閲覧数・人気記事の可視化 |

## 2. FAQ管理

### 2-1. 概要

よくある質問と回答を管理し、問い合わせを削減。

| 機能 | 説明 |
|------|------|
| FAQ登録 | 質問と回答のペアを登録 |
| カテゴリ分類 | 業務領域ごとに分類 |
| 検索 | キーワード検索 |
| フィードバック | 「役に立った」評価 |
| 問い合わせ連携 | 解決しない場合の問い合わせ導線 |

## 8. データモデル（ER図概要）

```
DocumentCategory（カテゴリ）
  └── has_many :documents

Document（ドキュメント）
  ├── belongs_to :category
  ├── belongs_to :author (User)
  ├── has_many :document_versions
  ├── has_many :document_attachments
  ├── has_many :document_tags
  ├── has_many :tags, through: :document_tags
  └── has_many :document_views

DocumentVersion（バージョン）
  └── belongs_to :document

DocumentAttachment（添付）
  └── belongs_to :document

Tag（タグ）
  └── has_many :documents, through: :document_tags

FaqCategory（FAQカテゴリ）
  └── has_many :faqs

Faq（FAQ）
  ├── belongs_to :category
  ├── belongs_to :author (User)
  └── has_many :faq_feedbacks

FaqFeedback（フィードバック）
  ├── belongs_to :faq
  └── belongs_to :user

Inquiry（問い合わせ）
  ├── belongs_to :submitted_by (User)
  ├── belongs_to :assigned_to (User)
  └── has_many :inquiry_replies

InquiryReply（返信）
  ├── belongs_to :inquiry
  └── belongs_to :replied_by (User)
```
