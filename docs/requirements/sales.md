# 営業機能 要件定義書

## 概要

### 目的
- 見積もり作成の迅速化（過去データからの自動算出）
- 運賃交渉時の資料作成支援（原価推移の可視化）
- 交渉履歴の管理と社内共有

### 関連機能
- 経営機能（車両別P/L、原価データ）
- 配車機能（実績距離、タリフ）
- 荷主管理（additional_features.md参照）

### メニュー構成

```
営業
├─ 見積もり
│   ├─ 見積もり一覧
│   ├─ 見積もり作成
│   ├─ テンプレート管理
│   └─ 単価マスタ
├─ 運賃交渉
│   ├─ 交渉案件一覧
│   ├─ 交渉資料作成
│   ├─ 原価推移レポート
│   └─ 交渉履歴
└─ 荷主分析
    ├─ 荷主別収益
    └─ 荷主別原価率
```

## 1. 見積もり機能

### 1-1. 概要

過去の運行実績や原価データから、素早く見積もりを作成できる機能。

| 機能 | 説明 |
|------|------|
| 自動単価算出 | 過去実績からキロ単価・時間単価を自動計算 |
| 高速代算出 | ルート情報から高速料金を自動取得 |
| 原価ベース見積 | 原価に利益率を加算した見積作成 |
| テンプレート | よく使うパターンを保存・再利用 |

### 1-5. 自動単価算出ロジック

```
キロ単価の算出:
1. 対象期間の運行実績を取得
   - 荷主別、車格別にフィルタ
   ↓
2. 運賃合計 ÷ 走行距離合計 = キロ単価
   ↓
3. 外れ値（平均±2σ以上）を除外して再計算
   ↓
4. 加重平均（直近月のウェイトを高く）
```

### 1-6. 高速代自動計算

```
高速代算出:
1. 出発地・到着地から座標を取得
   ↓
2. NEXCO API または Google Maps API でルート検索
   ↓
3. ETC料金（時間帯・曜日考慮）を取得
   ↓
4. 車格による料金区分を適用
   - 普通車 / 中型車 / 大型車 / 特大車
```

**連携API候補**:
- NAVITIME API（有料）
- Google Maps Directions API
- NEXCO料金検索API

## 2. 運賃交渉機能

### 2-1. 概要

荷主との運賃交渉を支援する機能。原価データを「見せる形」に整形し、交渉資料を素早く作成。

| 機能 | 説明 |
|------|------|
| 原価推移レポート | 年次・月次の原価推移を可視化 |
| 交渉資料作成 | 原価上昇を根拠とした値上げ資料 |
| 交渉履歴管理 | いつ・誰と・何を交渉したかを記録 |
| 合意事項管理 | 交渉結果の記録と追跡 |

|--------|--------|------|
| 燃料価格指数 | 全日本トラック協会 | 燃料費上昇の根拠 |

| トラック運賃指数 | 国土交通省 | 業界全体の運賃動向 |

## 6. データモデル（ER図概要）

```
Customer（荷主）
  ├── has_many :quotations
  ├── has_many :negotiation_cases
  └── has_many :price_references

Quotation（見積書）
  ├── belongs_to :customer
  ├── has_many :quotation_items
  └── belongs_to :created_by (User)

QuotationItem（見積明細）
  └── belongs_to :quotation

PriceReference（単価参照）
  └── belongs_to :customer (optional)

NegotiationCase（交渉案件）
  ├── belongs_to :customer
  ├── has_many :negotiation_histories
  ├── has_many :negotiation_documents
  └── belongs_to :lead_person (User)

NegotiationHistory（交渉履歴）
  ├── belongs_to :negotiation_case
  └── belongs_to :created_by (User)

NegotiationDocument（交渉資料）
  ├── belongs_to :negotiation_case
  └── belongs_to :created_by (User)
```
